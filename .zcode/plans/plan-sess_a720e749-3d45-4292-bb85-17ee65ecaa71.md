修复主页两个遮挡 bug，只改 `site/shared/home.css`：

## 根因
1. **记账被 4D 悬浮栏遮挡**：`.home-dock` 是 `position: absolute`，不占文档流高度；当头部 + 三行网格总高接近或超过 `.phone-home` 的 `min-height`（常见于 700–880px 高的窗口），悬浮栏（约 71px 高，距底 20px）盖住最后一排"记账 / CostTrace"文字。
2. **词汇学习 hover 图标被裁**：`.app-pager { overflow: hidden }` 垂直方向也裁剪，且网格 `padding: 0`，第一行图标顶边与裁剪边界齐平；hover 上浮约 4px 就被切掉。

## 修改（均在 `site/shared/home.css`）
1. `.app-pager` 基础规则（约 100-104 行）：
   - 加 `padding-top: 8px`（hover 上浮约 4px 的裁剪余量）；
   - 加 `padding-bottom: calc(max(20px, env(safe-area-inset-bottom)) + 79px)`（79px = 悬浮栏高约 71px + 8px 间距，共约 99px 预留空间，避免悬浮栏盖住最后一排应用名）。
2. `@media (max-width: 519px)` 内的 `.app-pager` 规则（约 369 行）加 `padding-bottom: 0`：移动端悬浮栏在文档流内，无需预留，避免产生多余空隙。

## 验证
- 运行 `npm run dev`，在 ≥520px 宽、高度约 700–880px 的浏览器窗口确认：最后一排"记账"名字完整可见、不被悬浮栏遮挡；hover"词汇学习"图标完整上浮、顶部无裁剪。
- 检查窄屏（<520px）移动布局无多余空隙、翻页滑动正常。
