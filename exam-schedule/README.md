# 考研一轮学习日程

一个无需后端的静态学习日程应用，支持手机与桌面端。完成状态、实际休息日和顺延任务均保存在当前浏览器的 `localStorage` 中。

## 本地查看

直接打开 `index.html` 即可使用；也可以在目录中启动任意静态文件服务器。

## 门户构建与部署

本应用源码由 Everything 4 Dudu 门户统一维护。请在门户根目录运行 `npm run verify`；门户根目录的 GitHub Actions 会在所有应用一起通过验证后发布整合站点。本目录不再连接独立远程仓库，也不再运行独立 Pages 工作流。

> 浏览器数据仅保存在当前设备和当前站点中，不会自动跨设备同步。
