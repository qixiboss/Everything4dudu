# 训练记录

纯前端训练记录网站，数据保存在浏览器 localStorage，无需服务器，打开即用。

## 使用方法

- **iPhone**：双击 `index.html` 打开即可，也可以加到主屏幕当应用用
- **电脑**：直接双击 `index.html`，或 `python3 -m http.server 8000` 后访问 localhost:8000

## 功能

- **今日训练**：每天 5 个动作 —— 俯卧撑、健腹轮、悬挂举腿、引体向上（各 4 组）+ 跑步/骑行
- **组计时**：点「开始」正向计时，做完点「开始休息」记录本组用时
- **组间休息**：可设置建议休息秒数；点「开始休息」后正向计时，休息好了点「完成休息，开始下一组」，自动开始下一组计时
- **有氧**：选择跑步或骑行，并以 5 分钟步进设置时长（1–240 分钟）；时长会计入统计。每天可自动建议和上次不同的项目
- **暂停**：顶栏按钮或空格键，暂停组计时和休息计时
- **热力图**：最近一个月训练情况，颜色深浅表示当天训练时长，点按查看详情
- **历史记录**：每天的训练明细（每组次数、用时），可删除
- **设置**：修改每个动作的默认目标、组间建议休息时长和自动轮换有氧开关

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式（移动端优先）
- `app.js` — 逻辑
